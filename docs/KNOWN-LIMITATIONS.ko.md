# 알려진 한계

[English](KNOWN-LIMITATIONS.md)

이 문서는 PCssak AroDamA 무료 Early Access `0.4.1`의 경계를 기록합니다. 2026-09-03에
공개 릴리스 노트·개인정보 안내와 대조했으며, 0.4.0에서 이어지는 설명을 새 시험 통과 결과로
표시하지 않습니다. 자동 시험 통과가 모든
앱·장치·정책·언어·클립보드 형식에서 같은 동작을 약속하지는 않습니다.

## 플랫폼과 배포

- Windows 11 Home/Pro x64는 주 지원 후보입니다. Windows 10 22H2 Home/Pro x64와 x86은
  제한적 호환 후보입니다.
- 네이티브 ARM64, Windows S 모드, Windows Server, Windows 11 x86, macOS, Linux, Wine은
  지원하지 않습니다.
- 설치본은 Windows Authenticode 미서명입니다. SmartScreen, Smart App Control, 백신이나 조직
  정책이 경고 또는 차단할 수 있습니다. Tauri 업데이트 서명은 업데이트 파일 무결성을 검증하지만
  Windows 게시자 신원을 증명하지 않습니다.
- 깨끗한 PC 설치·업데이트·제거·재부팅·절전 복귀, 기업 정책과 광범위한 백신 호환성은 실제 PC
  검증이 더 필요합니다.

## 클립보드 수집

- 텍스트·HTML·RTF·일반 비트맵 이미지·실제 파일 경로와 제한된 OLE 가상 파일을 지원합니다.
  앱 전용 또는 문서화되지 않은 형식은 무시하거나 지원되는 표현으로 축소할 수 있습니다.
- 암호 관리자·보호 창·기업 DLP·원격 데스크톱·브라우저·Office·샌드박스 앱의 동작은 서로
  다릅니다. 민감정보 필터는 위험을 줄이지만 모든 비밀이나 기밀 항목을 찾아낼 수 없습니다.
- 민감 텍스트 차단은 기본 꺼짐입니다. 이를 켜거나 제외 앱을 바꿔도 과거 기록을 검사하거나
  자동 삭제하지 않습니다. 기존 기록은 별도로 확인하십시오.
- 핵심 저장 내용은 로그인한 Windows 사용자 기준으로 암호화하지만, AroDamA가 표시·색인·복사·
  붙여넣기·내보내기·백업·복원하는 동안에는 평문이 프로세스 메모리에 존재해야 합니다. 침해된
  Windows 계정이나 실행 중인 악성 프로세스는 이 보호 경계 밖입니다.
- 수집 대기열과 페이로드에는 상한이 있습니다. 지나치게 크거나 손상된 내용, 매우 빠르게 바뀌는
  내용, 지연 렌더링 또는 접근 불가능한 내용은 UI를 멈추는 대신 건너뛸 수 있습니다.
- 이미지 미리보기는 모든 알파·색상 프로필·애니메이션·벡터·앱 전용 세부 표현을 재현하지 못할
  수 있습니다. OCR 사용 가능성과 정확도는 설치된 Windows 언어 팩과 원본 이미지 품질에
  좌우됩니다.

## 검색과 정리

- 검색은 암호화 후보 색인과 검증을 사용합니다. 마이그레이션·복구·대량 가져오기·색인 재생성
  직후 첫 검색은 이후 검색보다 느릴 수 있습니다.
- 날짜·출처·붙여넣기·기억 타임라인은 AroDamA가 로컬 PC에서 관찰하거나 시작한 사건을
  설명합니다. 포렌식 감사 로그·신뢰 시각·작성자 증명이나 다른 앱이 내용을 받아 표시·전송·
  저장했다는 증거가 아닙니다.
- Windows나 대상 앱이 안정적인 프로세스 신원을 제공하지 않으면 출처 앱 자동 감지는 없거나
  근사치일 수 있습니다.
- 큰 이미지가 많은 기록은 목록 썸네일과 페이지를 필요할 때 불러오더라도 디스크를 상당히 사용할
  수 있습니다.

## 붙여넣기

- Windows 사용자 인터페이스 권한 격리로 관리자 권한 또는 더 높은 권한의 대상에 자동 입력하지
  못할 수 있습니다. 이때 AroDamA는 안전하게 복사하고 사용자가 `Ctrl+V`를 누르도록 안내합니다.
- `sent` 또는 입력 호출 성공은 AroDamA가 동작을 보냈다는 뜻일 뿐, 대상이 내용을 받아 렌더링·
  전송·저장했다는 증거가 아닙니다.
- 포커스 변경·보안 입력란·원격 세션·접근성 도구·IME·키보드 배열·앱 단축키가 결과를 바꿀 수
  있습니다. 민감하거나 파괴적인 대상에서는 결과를 확인하십시오.
- 일반 텍스트 대체는 의도적으로 서식을 제거합니다. 복잡하거나 비공개인 형식은 정규화한 뒤
  복원하지 못할 수 있습니다.

## 삭제와 보관

- 사용자가 삭제한 항목은 영구 삭제하지 않는 한 무료 버전에서 정확히 24시간 복구할 수 있습니다.
  향후 플랜 경계를 위해 암호화된 삭제 데이터가 로컬에 최대 30일 남을 수 있지만 `0.4.1`은
  24시간 이후 복구 기능을 제공하지 않습니다.
- AroDamA 복구 보관함은 Windows 휴지통과 별개이며 어느 한쪽을 비워도 다른 쪽은 비워지지
  않습니다.
- 논리 삭제·DB 압축·파일 제거는 SSD 웨어 레벨링, 파일 시스템 저널, 백업, 크래시 덤프, 메모리,
  저장장치 스냅샷에서 즉시 물리 삭제됨을 보장하지 않습니다.
- 자동 개수·보관 정리는 오래된 기록을 사용자가 삭제한 복구 보관함을 거치지 않고 제거할 수
  있습니다. 영구 삭제한 데이터는 AroDamA로 복구할 수 없습니다.

## 백업과 복원

- PCSSAK도 백업 암호를 복구할 수 없습니다. 암호를 잃으면 해당 백업을 사용할 수 없습니다.
- 복원은 병합이 아니라 현재 로컬 데이터 교체입니다. 오래된 백업이 이후 삭제한 데이터를 다시
  가져올 수 있으므로 먼저 별도 백업을 만들고 검증하십시오.
- 중단·손상·잘못된 버전·잘못된 암호·인증 실패 백업은 안전하게 거부해야 하지만 저장매체 고장이
  불가능해지는 것은 아닙니다.
- 백업은 암호화되어도 민감한 사용자 데이터를 담습니다. 암호를 분리 보관하고 공개 Issue에
  백업을 올리지 마십시오.

## 제품과 서비스 경계

- `0.4.1`은 무료 Early Access입니다. 사용자에게 보이는 Pro 구매·결제 처리·계정·클라우드
  클립보드 동기화·원격 라이선스 활성화·광고·분석 기능이 없습니다.
- 로컬 최대 30일 복구 기반이 있다고 해서 이 릴리스에 30일 복구를 구매하거나 사용할 수 있는
  것은 아닙니다.
- 자동 시험은 화면 읽기 도구·키보드 전용 사용성 검수, 여덟 언어 원어민 검수, 관할별 법률 검토,
  전체 지원 Windows와 제3자 앱 조합 시험을 대신하지 않습니다.

이 경계에서 데이터 손실·손상·위험 동작이나 잘못된 보안 설명이 발생하면 해당 사용을 중단하고
[SUPPORT.md](../SUPPORT.md)를 따르거나 [SECURITY.md](../SECURITY.md)에 따라 보안 문제를
비공개로 신고하십시오.
