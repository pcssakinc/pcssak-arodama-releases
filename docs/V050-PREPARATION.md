# AroDamA 0.5.0 준비 현황

확인일: 2026-09-20. 현재 상태: 개발·검증 중, 다운로드 보류.

0.5.0의 준비 안내를 공개하되 설치 파일과 자동 업데이트는 아직 제공하지 않습니다.
공식 홈페이지의 소개·다운로드 화면에서도 같은 상태를 안내합니다.
다운로드 버튼은 실제 비활성 상태로 제공하며 이전 설치 파일을 0.5.0으로 연결하지 않습니다.

## 이번 시험 버전에서 다루는 내용

- 부드러운 밝은 테마, 통일된 글자 크기와 PC 전송 화면 가독성.
- PC 등록 중 입력 보존, 보내기 전 상대방 등록 확인, 파일 선택·수락 대기·전송 상태 안내.
- 순서 붙여넣기의 시작·진행·중단 안내와 중복 입력 방지.
- 기록과 붙여넣기 진행 상태의 저장 내구성, 검색 계산과 저장소 점유 감소.
- 연속 복사 수집의 읽기·저장 분리, 제한된 대기 공간, 정책 변경 시 대기 내용 폐기.
- 기존 자료를 바꾸지 않는 스토어 이전 사전검사 기반.

위 항목은 시험 버전의 개발 범위입니다. 자동 검사 통과는 모든 Windows 구성·실제 두 PC 전송·
외부 프로그램 붙여넣기·장시간 사용의 실측 완료를 의미하지 않습니다.
실제 스토어 자료 이전·설치 수명·구매 연동과 유료 판매 준비는 별도 완료가 필요합니다.

## 공개 범위

현재 제공하는 것은 준비 안내입니다. 0.5.0의 설치 파일, 다운로드 주소, 새 자동 업데이트
매니페스트는 공개하지 않습니다. 앱 자체 소스와 내부 시험 자료는 비공개로 유지합니다.
기존 0.4.2 릴리스와 그 서명·해시·법률 문서는 당시의 기록으로 보존하며 덮어쓰지 않습니다.

0.5.0 준비 안내가 Microsoft Store 판매 시작·외부 보안 인증·무오류 보장을 뜻하지 않습니다.
정식 공개 상태가 결정되면 이 문서와 [공식 제품 페이지](https://pcssak.com/arodama)를 함께 갱신합니다.

## 2026-09-20 업무 기록

0.5.0 준비 상태와 기존 0.4.2 문서의 적용 범위를 구분하는 안내를 추가했습니다.
릴리스 설치 파일·서명·자동 업데이트·기존 법률 정본은 변경하지 않았습니다.
홈페이지 준비 안내를 운영에 반영하고 한국어·글로벌 도메인의 8언어 소개·다운로드
16페이지에서 실제 비활성 버튼과 설치 파일 주소 비노출을 확인했습니다. 이 검사에서
설치 파일을 요청하거나 프로그램을 설치하지 않았습니다. 프로그램의 최종 코드 검증과
비공개 시험본 제작은 별도 진행 상태로 관리합니다.
